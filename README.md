# Minecraft PvP Resource Pack

Ein vanilla-kompatibles Java-Edition Resource Pack (Ziel: MC 1.26.2), das mehrere beliebte PvP-Utility-Fixes in einem Pack bündelt.

## Ziel-Features (V1, nah an Vanilla)

- Low Fire Overlay
- Tiny Tools (kleinere Schwerter/Äxte/Spitzhacken in der Hand)
- Outlined Cobwebs
- Low/Lower Shield Position
- Shield-Cooldown-Farbe (rot bei disabled, faded zurück zu normal)
- Bogen-Ladebalken-Gradient (rot → grün, mehr Stufen als Vanilla)
- Fishing Bobber wird nah an der Kamera unsichtbar/klein
- Kein Kürbis-Blur-Overlay
- Reduzierte Partikel (Crit, Sweep, Totem, Effect)
- Konsistente Ess-/Trink-Animation
- Crystal-PvP-Texturen (End-Kristall, Obsidian, Totem, Anker)

V2 (später): eigener visueller Stil, gleiche Funktionalität.

## Struktur

```
pack.mcmeta
assets/minecraft/...
```

## Installation

Ordner/Zip in `%appdata%/.minecraft/resourcepacks` (Windows) bzw. `~/.minecraft/resourcepacks` (Linux/Mac) legen und im Spiel unter Optionen → Resource Packs aktivieren.

**Hinweis:** "Kein Hurt-Cam-Wackeln" ist kein Pack-Feature, sondern ein Vanilla-Setting: Optionen → Bedienungshilfen → Damage Tilt aus.
